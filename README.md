# 快下 FastDown · Windows 安装版

一款 Windows 桌面下载器：视频/音频平台解析、网页真实地址嗅探、文件直链多线程下载、批量下载。
内置 yt-dlp / ffmpeg / aria2c，装好即用，不需要另外配环境。

> 本仓库只放**发布包与使用说明**，不含源码。

## 下载

到 [Releases](../../releases/latest) 页面下载最新版：

| 文件 | 说明 |
|---|---|
| `FastDown_v6.1_安装版_win64.zip` | 安装版（含安装向导 + 安装包 + 浏览器扩展 + 使用手册） |

解压后双击 `FastDown_Setup.exe` 安装。**`FastDown` 文件夹必须和 `FastDown_Setup.exe` 放在一起**，安装程序要从里面复制文件。

## 系统要求

- Windows 10 / 11（64 位）
- 无需管理员权限即可运行；安装到 `Program Files` 时需要管理员权限
- 浏览器扩展支持 Chrome / Edge / 360（Firefox 暂不推荐）

## 安装步骤

1. 解压 zip，双击 `FastDown_Setup.exe`
2. 选择安装位置 → 下一步 → 完成
3. 安装完成后启动「快下FastDown」，客户端会监听本机 `127.0.0.1:18586` 供扩展调用
4. 装浏览器扩展（三选一，**只装一个**，重复装会出现多条悬浮条）：
   - **Chrome**：`chrome://extensions` → 打开「开发者模式」→「加载已解压的扩展程序」→ 选安装目录下 `浏览器扩展\Chrome(谷歌浏览器)`
   - **Edge**：`edge://extensions` → 打开「开发人员模式」→「加载解压缩的扩展」→ 选 `浏览器扩展\Edge(微软浏览器)`
   - **360 浏览器**：扩展管理 → 开发者模式 → 加载已解压 `浏览器扩展\360浏览器`
5. 打开任意视频页，页面右上角出现「⬇ 快下」悬浮条即装好

> Chrome 137 以后，直接拖 `.crx` 安装会提示"未列在 Chrome 应用商店"并**默认停用**，需要手动把开关拨开；用"加载已解压"更省事。

## 使用

- **悬浮条**：自动识别当前页面可下载的视频/音频，点开可按分辨率、字幕、音频单独下载
- **点扩展图标**：按类型列出本页资源（图片 / 视频 / 音频 / 字幕 / 歌词 / 文档 / 磁力种子），勾选后批量推送
- **点下载链接**：文件直链、磁力、种子自动接管，交给客户端多线程下载
- **批量下载**：把多个链接丢进客户端即可排队

## 常见问题

**悬浮条显示"连不上客户端"**
先启动「快下FastDown」桌面客户端；客户端会占用 `127.0.0.1:18586`。若客户端已在运行仍报错，关掉客户端重新打开一次。

**点了下载没反应 / 任务 0%**
多为该链接需要登录或已失效。可在客户端「高级选项」里配置 Cookie 来源，或回到原网页重新复制最新链接。

**YouTube 解析失败**
需要在客户端设置里填写代理（如 `http://127.0.0.1:7890`），并在代理软件里换一个非机房节点。
