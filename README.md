- **悬浮条嗅探**：打开视频页右上角出现「⬇ 快下」，自动跟随当前视频，列出真实文件名 + 分辨率 + 大小

- **画质与音轨**：4K ~ 480P 可选，只下音频出 MP3；音轨自动优选 AAC，杜绝「有画面没声音」

- **全自动代理**：境外站点自动识别走系统代理，国内站直连，不用手动切换
- **任务持久化**：关掉软件重启任务还在，支持右键重试、打开所在文件夹

## 🔧 安装步骤

1. 解压 zip，双击 `FastDown_Setup.exe`
2. 选择安装位置 → 下一步 → 完成（可勾选「创建桌面快捷方式」「开机自动启动」）
3. 启动「快下FastDown」，客户端会监听本机 `127.0.0.1:18586` 供浏览器扩展调用
4. 装浏览器扩展（**三选一，只装一个**，重复装会出现多条悬浮条）：

   | 浏览器 | 操作 |
   |---|---|
   | Chrome | `chrome://extensions` → 打开「开发者模式」→「加载已解压的扩展程序」→ 选安装目录下 `浏览器扩展\Chrome(谷歌浏览器)` |
   | Edge | `edge://extensions` → 打开「开发人员模式」→「加载解压缩的扩展」→ 选 `浏览器扩展\Edge(微软浏览器)` |
   | 360 浏览器 | 扩展管理 → 开发者模式 → 加载已解压 `浏览器扩展\360浏览器` |

5. 打开任意视频页，右上角出现「⬇ 快下」悬浮条即装好

> Chrome 137 以后直接拖 `.crx` 会提示「未列在 Chrome 应用商店」并**默认停用**，需要手动把开关拨开；用「加载已解压」更省事。

## 📖 怎么用

1. **粘贴下载（最常用）**：复制视频/文件链接 → 粘到主窗口顶部输入框 → 点「添加任务」→ 选画质
2. **悬浮条**：视频页右上角点「⬇ 快下」，自动嗅探本页视频，勾选画质直接下
3. **本页资源面板**：点扩展图标，按类型勾选整页资源批量下载
4. **磁力 / BT**：粘贴 `magnet:` 或点「🧲 打开种子」选本地 `.torrent`
5. **批量**：B站合集 / 收藏夹 / 博主主页、YouTube 播放列表 / 频道、TikTok 主页，粘贴后弹列表勾选

## ❓ 常见问题

**悬浮条显示「连不上客户端」**
先启动「快下FastDown」桌面客户端（它占用 `127.0.0.1:18586`）。若客户端已在运行仍报错，关掉重开一次。

**点了下载没反应 / 任务 0%**
多为链接需要登录或已失效。可在「设置」里导入浏览器 Cookie，或回原网页重新复制最新链接。

**YouTube / TikTok 慢或失败**
软件会自动走代理，请确保代理软件已开启并换一个非机房节点。

**分类面板里视频/音频是空的**
这类资源边播边加载，先在网页里播放几秒再点扩展图标。

**普通文件直链会弹画质选择框吗**
不会。`.zip` / `.exe` / `.pdf` 等自动按文件类型直下，不走视频解析。
